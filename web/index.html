Le cose utili da sapere

Dove vengono messi i file?

Le nuove cartelle vengono create dentro la cartella che scegli. Nell’anteprima trovi il percorso preciso di ogni file. Se scegli “Non spostare”, cambiano soltanto i nomi.

La lingua cambia i nomi delle cartelle?

No. La lingua riguarda l’interfaccia. Le cartelle delle categorie mantengono i nomi italiani (Immagini, Documenti, Archivi, Audio, Video, Codice, Altro), così i percorsi rimangono coerenti quando cambi lingua.

Che data viene usata per i mesi?

La data di ultima modifica del file. Per le foto può essere diversa dalla data di scatto. Controlla sempre l’anteprima.

E se due file hanno lo stesso nome?

I file esistenti non vengono sovrascritti. Quando necessario, viene aggiunto un numero al nome: vedrai il risultato nell’anteprima.

Che cosa succede ai file esclusi?

Restano dove sono. I file nascosti, i collegamenti simbolici e i file non inclusi nelle categorie scelte vengono ignorati. Le cartelle protette non vengono esplorate.

Posso annullare dopo aver chiuso l’app?

Sì, la cronologia viene salvata sul computer. Il ripristino verifica che i file siano ancora al loro posto e non siano cambiati. Se li modifichi o sposti con un’altra app, potrebbe non essere possibile annullare automaticamente.

I miei file vengono caricati online?

No. Il programma lavora sul tuo computer, senza account, servizi cloud o API a pagamento. I file di esempio sono una cartella separata, creata solo per provare l’app.
